# Fcitx5 打字统计

Fcitx5 输入法打字统计工具，实时统计输入字数，并提供文人段位系统、速度追踪和可视化仪表盘。

> 本项目核心算法参考自 [dde-tray-wordcount](https://atomgit.com/hebowen/dde-tray-wordcount.git)，在此基础上进行了修改，使之能够运行在任何Linux系统。

---

## ✨ 功能特性

### 📊 字数统计
- 实时统计中英文输入字数
- 支持 CJK 字符（中文/日文/韩文）统计
- 可选的标点符号和 Emoji 统计

### 🏆 段位系统
**6套预置方案，自由切换：**

| 方案 | 段位体系 | 适合人群 |
|------|---------|---------|
| 文人雅称 | 蒙童 → 文圣 | 传统文化爱好者 |
| 科举制 | 童生 → 文正 | 历史爱好者 |
| 武道修行 | 学徒 → 武帝 | 武侠迷 |
| 修仙境界 | 凡人 → 渡劫 | 仙侠小说读者 |
| 现代职场 | 实习生 → CEO | 打工人 |
| 游戏段位 | 青铜 → 传说 | 游戏玩家 |

- 每个段位包含 9 品（九品 → 一品）
- 字数门槛按对数曲线设计，新手升级快，后期有挑战
- 托盘图标支持显示今日字数或段位进度环

### 📈 统计仪表盘
- 今日字数/提交次数/打字速度
- 字词分布统计（1字/2字/3字/4字/5+字）
- 词组连打率分析
- 近7日趋势图
- 完整段位信息与里程碑

### 🎨 界面定制
- 支持亮色/暗色/跟随系统主题
- 详情面板悬浮显示，不干扰工作
- 托盘图标个性化设置

### 💾 数据管理
- 数据持久化存储（SQLite）
- 导入/导出 JSON 格式
- 清理旧数据
- 数据库压缩（VACUUM）

---

## 🚀 快速开始

### 依赖
- Qt6 (Core, Widgets, DBus, Sql)
- Fcitx5 (需要 D-Bus 支持)
- CMake 3.16+

### 编译安装

```bash
git clone https://github.com/yourusername/fcitx5-wordcount.git
cd fcitx5-wordcount
mkdir build && cd build
cmake ..
make -j$(nproc)
sudo make install
```
