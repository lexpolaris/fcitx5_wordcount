# Fcitx5 打字统计

Fcitx5 输入法打字统计工具，实时统计输入字数，并提供文人段位系统、速度追踪和可视化仪表盘。

> 本项目核心算法参考自 [dde-tray-wordcount](https://atomgit.com/hebowen/dde-tray-wordcount.git)，在此基础上进行了修改，使之能够运行在任何Linux系统。

## ✨ 功能特性

- **实时统计**：通过 D-Bus 监听 Fcitx5 输入法上屏事件，实时统计字数
- **智能计数**：支持中英文混排，中文按字数统计，英文按单词统计
- **文人段位**：8 段位 × 9 级共 72 级段位系统，从"蒙童"到"文圣"
- **速度追踪**：60 秒滚动窗口统计打字速度（字/分钟）
- **数据持久化**：SQLite 数据库存储，支持历史数据查询
- **可视化面板**：
  - 悬浮详情面板（今日字数、段位进度、速度、趋势图）
  - 统计仪表盘（今日详情、效率分析、7日趋势、段位信息）
- **托盘图标**：支持显示今日字数或段位进度
- **主题支持**：跟随系统、亮色、暗色三种模式
- **开机自启**：可配置开机自动启动

### 模块职责

| 模块 | 职责 |
|------|------|
| **Fcitx5Monitor** | 通过 dbus-monitor 监听 Fcitx5 输入法信号，提取上屏文本 |
| **CharCounter** | 字数统计算法，支持 CJK、英文单词、标点、Emoji 计数 |
| **StatisticsEngine** | 数据核心，管理字数统计、速度追踪、段位计算 |
| **DatabaseStorage** | SQLite 数据库读写，线程安全 |
| **SpeedTracker** | 60 秒滚动窗口速度追踪 |
| **LevelSystem** | 段位系统定义与计算 |
| **TrayIconManager** | 系统托盘图标管理与菜单 |
| **DetailPanel** | 悬浮详情面板（自管理数据） |
| **InsightPanel** | 统计仪表盘（自管理数据） |
| **ConfigManager** | 配置管理（QSettings） |
| **ThemeHelper** | 主题切换与颜色管理 |

## 🔧 编译与安装

### 依赖

- Qt 6.x (Core, Widgets, DBus, Sql, Network)
- CMake 3.16+
- C++17 编译器
- Fcitx5 (运行时)
- dbus-monitor (运行时)

Qt Network用于进程间通信


### 安装

```bash
# 克隆项目
git clone https://github.com/yourusername/fcitx5-wordcount.git
cd fcitx5-wordcount

# 创建构建目录
mkdir build && cd build

# 配置
cmake ..

# 编译
make -j$(nproc)

# 安装（可选）
sudo make install

# 运行
./fcitx5_wordcount
```
